# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
private vulnerability reporting flow for this repository. If that flow is not
available, email [support@doxmind.com](mailto:support@doxmind.com) with
`Security report` in the subject line.

Include affected versions, steps to reproduce, impact, and any proof of
concept. Do not include private user files unless they are necessary to
demonstrate the issue.

## Supported versions

Security fixes target the current public desktop release. Older releases may
receive guidance to update rather than a backport.

## Scope

The most useful reports concern the packaged desktop app, local filesystem
operations, Markdown parsing and export, update verification, dependency
security, and the release pipeline. doXmind has no hosted document service,
cloud sync, or built-in AI provider runtime.
