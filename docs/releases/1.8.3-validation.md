title and body without application chrome. The Markdown source, complete legacy
artifact family, and workspace entries remained byte-identical. Cancellation

## Squirrel update gate

A clean application directory was populated from the public `v1.8.2` update
ZIP at its recorded SHA-256
`805a5ecda7cb46bc142386e423436743eaecd83f82f04f8790b24b15d57ab3ee`.
The signed `1.8.2` App contacted a loopback Squirrel JSON feed that served the
unchanged Draft `1.8.3` ZIP at SHA-256
`cba631aa41bc8d45dfa967aa4eb61d0933a33861b800deadff85aa1922261858`.

Squirrel emitted checking, available, and downloaded events for `1.8.3`.
`quitAndInstall` handed the update to ShipIt, which replaced the installed App
and relaunched it with one live Renderer. The relaunched App reported version
`1.8.3`; its deep signature and stapled ticket remained valid, and its ASAR
matched the candidate at
`e47025f48858fbb30cb8064111309dc7ce2bfa4713d73c534ded2b9db0dfdc7a`.

After a clean quit, the updated App was cold-launched through the packaged GUI
suite with fresh isolated user data and passed all 23 checks again. The test
never replaced `/Applications/doXmind.app` and did not open or modify a user
workspace.
