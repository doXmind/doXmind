# doXmind 1.8.1 release notes

doXmind 1.8.1 establishes the fully local, Markdown-native workspace on one
Electron desktop runtime. A Page is one portable `.md` or `.markdown` file;
Markdown is the editor state and the user's folder remains the source of truth.

## Native Markdown Pages

- Every Page uses the source-backed Block editor. Headings, lists, tasks,
  quotes, tables, code, math, Mermaid, callouts, portable Toggles, Wiki Links,
  embeds, and unsupported raw Markdown all round-trip through canonical source.
- Block move, duplicate, delete, paste, undo, slash commands, autosave, and
  external-change protection operate directly on Markdown spans.
- TipTap and ProseMirror runtimes and dependencies are removed. Tauri and the
  former Rust Page runtime are also removed; Electron is the only desktop shell.

## Local knowledge workspace

- YAML frontmatter properties, tags, aliases, dates, and exact Wiki-Link
  relations are edited with revision-guarded, lossless patches.
- Wiki navigation, backlinks, unresolved links, unlinked mentions, Page graph,
  Daily Notes, and Page/heading/block embeds are rebuilt from local Markdown.
- Read-only Table, Board, and Calendar Collections derive their rows, formulas,
  relations, and rollups from Pages without creating a database sidecar.
- Verified pasted or dropped images are copied without overwrite into local
  `assets/` and referenced with portable relative Markdown.

## Attachments and legacy recovery

PDF, spreadsheet, HTML, image, and other non-Markdown files remain ordinary
Attachments. They are read-only in doXmind and can be revealed or opened in the
system application; this release does not recreate the removed PDF or workbook
editors.

Existing Page, PDF, and spreadsheet sidecars are preserved as legacy evidence.
The explicit recovery action exports a Markdown report containing exact legacy
artifact bytes or editor-state JSON without rewriting the source, `.doxmind`,
`.bak`, `.lock`, or `.corrupt-*` files. Keep the complete artifact family until
unique edits have been independently recovered.

## Printer-independent PDF export

Page export is fully local. Electron waits for the source-backed view to settle,
generates PDF bytes in-process with `webContents.printToPDF`, and atomically
writes the destination selected in the native Save dialog. It requires no
printer or driver, starts no Python/FastAPI service, and creates no sidecar.

## Before upgrading

Back up the workspace folder. If an older doXmind version edited a PDF or
workbook, preserve the original Attachment and every adjacent legacy artifact
together. For the narrowly validated 1.7.8 fallback procedure, see the
[legacy validation record](1.8.0-legacy-validation.md); run an old build only
against a complete duplicate, never the original workspace.

## Current boundary

doXmind 1.8.1 has no account, cloud sync, collaboration, telemetry, billing, or
built-in AI runtime. Attachments are edited externally. Markdown-to-DOCX export
is not included in this release.
