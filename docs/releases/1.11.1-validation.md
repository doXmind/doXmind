## Downloaded candidate GUI and file preservation

The packaged Electron acceptance suite launched the App extracted from the
downloaded update ZIP with isolated user data and a temporary workspace. All
22 checks passed, including native menus, source-backed Block editing,
Collections, image import, local PDF export and cancellation, read-only
Attachments, settings, and renderer startup/crash recovery. The report recorded
no renderer page errors or console errors. PDF export and cancellation left the
Page source, legacy artifact bytes, and workspace inventory unchanged.

The public product no longer exposes the old Page or Attachment recovery
commands. Native workspace tests confirm those command names are absent and
that normal Page operations preserve existing legacy bytes.

## Quarantined Finder installation

A copy of the downloaded DMG was marked with `com.apple.quarantine` and mounted
read-only. Finder copied its App into an isolated test folder; the copied App
retained quarantine, passed deep signature and Gatekeeper checks, and opened
through LaunchServices. The running process used an isolated user-data path and
macOS App Translocation. Accessibility confirmed the first-run welcome screen.
No security protection was disabled.
