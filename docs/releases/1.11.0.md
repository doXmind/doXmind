# doXmind 1.11.0

doXmind 1.11.0 focuses on local Markdown editing, clearer search, and a smaller
interface. A Page remains one portable `.md` or `.markdown` file. The macOS
Apple-silicon app runs entirely in Electron without a Python service.

## Editing

- Multi-line paragraphs keep bold, italic, links, and other supported inline
  formatting visible while editing. Shift+Enter adds a line within the Block;
  Find highlights the correct text in CRLF files.
- Turn into works on multi-line Blocks and from the floating toolbar. Headings
  join wrapped lines, and lists retain their continuation indentation.
- Active formatting buttons use the editor accent and show shortcut tooltips.
- Table column handles remain reachable. Clicking a visible Block no longer
  scrolls the Page unexpectedly; keyboard navigation still brings it into view.
- The gutter + opens the insertion menu before creating content. Only the
  relevant Block's gutter controls are shown.
- Tab-indented lists can be outdented, and nested list content remains visible.
  YAML list-form metadata is read while untouched frontmatter remains intact.

## Search and navigation

- Workspace search groups matches by Page, highlights them, and opens the
  matching line. File/path/content filters, negation, OR, quoted phrases, and
  regular expressions support more precise queries.
- The command palette ranks file names with the quick-switcher matcher. Its
  full-text search action hands the query to workspace search instead of
  scanning every Page a second time.
- The title bar no longer repeats the sidebar magnifier. Cmd/Ctrl+P and the
  Edit menu still open the command palette.
- Split panes support two different Pages, independent editing, a draggable
  divider, and moving tabs between panes.
- Hotkeys can be rebound in Settings, and the interface can be switched to
  Chinese in Appearance.

## A smaller product surface

- The Properties, Backlinks, Graph, History, and tag panels have been removed.
  Existing frontmatter and inline source are preserved; this release does not
  provide those panels or automatic Page-history snapshots.
- Legacy recovery interfaces have been removed. Existing `.doxmind`, `.bak`,
  `.lock`, and `.corrupt-*` files remain untouched; they are not imported into
  the Page editor or rewritten.
- Non-Markdown files already in a workspace remain read-only Attachments with
  external-open and reveal actions. The import door accepts Markdown Pages.
- README imagery and documentation were refreshed around the current editor.

## Boundaries

Unsupported Markdown stays editable as raw source. Canvas and `.base` editors,
accounts, cloud sync, built-in AI, and a plugin marketplace are not included.
Local Wiki Links, embeds, images, and Page PDF export continue to work from the
files on disk.
