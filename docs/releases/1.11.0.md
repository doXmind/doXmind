# doXmind 1.11.0 release notes

doXmind 1.11.0 is an Obsidian-compatibility release. A vault written in Obsidian
could be opened before this release, but not read: its tags were invisible, its
tab-indented lists could not be edited, and the files it keeps beside your notes
were absent from the sidebar. This release is about a vault arriving intact, and
about the surfaces you reach for once it has.

## A vault written elsewhere arrives whole

- `tags:` and `aliases:` written as a YAML list — the shape Obsidian writes by
  default — are read. They used to parse as an empty string, so every tag and
  alias in an imported vault was silently missing. `tags: [a, b]` works too;
  previously only a fully quoted JSON array did.
- Editing one such list keeps it a list, keeps its indentation, and leaves the
  lists around it byte-identical.
- Shift+Tab outdents a tab-indented list. Obsidian indents with tabs by default,
  and the outdent measured indentation in characters while rebuilding it as
  spaces, so it always failed — taking Backspace at the start of a line and
  Enter on an empty item down with it, which left an empty tab-indented item
  with no key that could escape it.
- An ATX heading indented up to three columns is a heading, not an unrepairable
  grey box.
- The sidebar shows what is on disk: images, `.canvas`, `.base`, and any other
  file, plus folders that hold none of them. `assets/` — the folder doXmind's
  own image paste writes into — was invisible in doXmind.

## Things that were on disk and not on screen

- `%%comment%%` is no longer rendered. Text an author marked as not part of the
  document was being displayed in full.
- A fenced code block or a second paragraph inside a list item renders. Only the
  item's first paragraph used to, so that content survived every edit invisibly.
- `==highlight==` renders as a highlight.
- Workspace search reports every match in a Page, not just the first, and at
  line numbers that point where they say: they were counted over the frontmatter,
  which the editor's document does not contain.

## Finding things

- The left sidebar has a search view: results grouped by Page, collapsible, with
  per-Page and total counts and the match highlighted. Clicking one opens the
  Page at that line.
- Search understands operators: `file:` `path:` `tag:` `content:`, `-` to
  negate, `OR`, `"quoted phrases"` and `/regex/`. A plain query behaves as before.
- The quick switcher has a text input. It was a list of the ten most recently
  changed files and confirmed when you released the modifier key. It now matches
  by name, path, initials, subsequence and pinyin, shows folders when two Pages
  share a name, and offers to create a Page that does not exist.
- Find-in-Page marks the match it is counting — the highlight was derived from a
  selection that is consumed as soon as it is applied — and gains match-case, a
  regular-expression mode, and replace on `Cmd/Ctrl+Alt+F`.

## Links and tags

- Typing `[[` suggests Pages, headings and aliases, and inserts a link that
  resolves: a bare name while it is unique, a path once two Pages share one.
- An inline `#tag` is a tag: rendered as a pill, nested through `/`, counted in a
  tag pane, and searchable by clicking it. Unicode tags work, so `#项目` is a tag.
  `C#`, `#1984` and `src/lib#anchor` are not.
- Clicking an unresolved `[[Wiki Link]]` creates the Page it names and opens it.
- The unlinked-mentions list can turn a mention into a link where it stands.

## Reading and recovering

- A heading folds its section and a list item folds its subtree, with fold-all
  and unfold-all in the command palette. Folding is a view, never written to the
  file, and PDF export unfolds first so a folded section cannot omit itself.
- A Page write records the bytes it replaced, throttled and bounded, in app data
  rather than beside your notes. History browses and restores them through the
  ordinary guarded write.

## Keys, menus and language

- Every command lives in one registry, so all of them are in the command palette
  and all of them can be rebound in Settings → Hotkeys. Five were reachable from
  the palette before, and none could be rebound.
- The keys follow Obsidian: `Cmd/Ctrl+O` is the quick switcher, `Cmd/Ctrl+P` the
  command palette, `Cmd/Ctrl+Alt+O` Open File. `Cmd/Ctrl+K` is the editor's link
  editor.
- Right-clicking in the editor opens a menu. There was none: the renderer
  deferred to a native menu that Electron only provides once the main process
  registers one, so spell-check suggestions were unreachable.
- Tabs reorder by drag and have a context menu.
- The interface can be switched to Chinese in Settings → Appearance. The Chinese
  bundle has been complete and shipped for several releases, selectable only by
  editing a cookie by hand.

## Two Pages at once

- Split right puts a second Page beside the first, from the command palette or
  the tab's context menu. Each pane is a real editor: it saves, undoes and
  exports on its own, and a 2px bar marks the one your next keystroke reaches.
- A tab dragged onto a pane opens there. A Page is only ever in one pane —
  dropping it onto the pane that already holds it does nothing, and dropping the
  other pane's Page trades the two rather than opening a second copy, which would
  give one file two independent edit histories.
- The divider drags, double-clicks back to even, and stops before either column
  gets too narrow to read.
- Close the other pane, or focus it, from the palette.

## Known limitations

- Open tabs do not survive a restart, because the workspace itself does not: a
  cold start lands on the welcome screen.
- A blockquote or callout containing a fence, a list or another quote is shown as
  raw Markdown rather than rendered. Its content is visible and editable.
- Inline math (`$x$`), footnotes, reference-style links and definition lists
  remain exact raw Markdown.
- There is no Canvas, no `.base` view, and no importer; `.canvas` and `.base`
  files are listed but opened externally.
- The graph is a bounded neighbourhood of the open Page, not a whole-workspace
  force-directed graph.
- The native menu bar is English regardless of the interface language.
- Setext headings are recognised as headings by the editor, but not by the
  outline label, the document outline command, or heading embeds.
