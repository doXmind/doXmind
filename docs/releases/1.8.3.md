# doXmind 1.8.3 release notes

doXmind 1.8.3 makes the native Markdown editor calmer and more direct while
keeping every Page as one portable source file.

## Semantic inline editing

- Supported inline Markdown appears as formatted text while editing, with
  source delimiters hidden from the normal writing surface.
- Text selection opens a compact formatting toolbar for Block type, bold,
  italic, strike, links, and inline code.
- Find keeps keyboard focus and highlights matches across the semantic
  projection, including local image syntax.

## Direct Block controls

- Persistent row chrome is replaced by a quiet hover gutter with Add and a
  six-dot Block handle.
- The searchable Block menu provides Turn into, copy Markdown, duplicate, move,
  and delete actions without covering the writing surface.
- Heading rhythm, nested-list indentation, selection spacing, and light/dark
  contrast are refined for a cleaner Page canvas.

## Structural editing

- Contiguous multi-Block selection supports keyboard and pointer extension,
  copy, cut, duplicate, delete, move, paste, undo, and redo.
- List operations include the complete descendant subtree, so moving or
  changing a parent does not detach its children.
- Indent, outdent, empty-list Enter, and nested-list Backspace preserve
  canonical hierarchy; multi-Block paste is one atomic operation.

## Markdown remains the source of truth

- Every operation writes canonical Markdown and preserves untouched source,
  line endings, and unsupported syntax.
- There is no TipTap or ProseMirror runtime and no Page sidecar. Unsupported
  structures remain editable as raw Markdown.
- The release stays fully local in the single Electron desktop runtime. It adds
  no account, cloud service, AI runtime, telemetry, or Attachment editor.
