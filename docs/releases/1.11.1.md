# doXmind 1.11.1

doXmind 1.11.1 is a desktop reliability release focused on safe file actions,
predictable navigation, and accurate PDF output.

## Files and tabs

- Closing a workspace with unsaved changes prompts before switching.
- Closing tabs waits for pending saves. Deleted Pages no longer return from a
  stale editor cache, and switching back to a Page rereads its saved source.
- Renaming a Page submits once when Enter and blur happen together. Creating an
  `Untitled` Page retries when its proposed name already exists.
- File actions target only the focused window; opening a missing Page no
  longer creates a ghost editor. File-item actions and tab reordering now keep
  the intended target and order.

## Search, editing, and export

- Workspace search honors excluded directories, and ambiguous Wiki Links do
  not navigate to an arbitrary match.
- Disabled table menu items no longer receive pointer actions. File-action
  portals no longer activate an inactive Page.
- Conflict alerts stay below the window chrome, and collapsed toggles are
  included in PDF output. macOS PDF export uses a CJK-capable font.
