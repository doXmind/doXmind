## Gate

- [x] `package.json` and `package-lock.json` agree on `1.10.0`.
- [x] 1251 unit tests across 96 files, 69 Electron native-boundary tests, and
      266 backend tests pass on the release commit.
- [x] Chromium GUI acceptance passes all 595 cases, including the per-Block
      interaction matrix, history granularity, IME atomicity, and byte
      integrity.
- [x] Frontmatter patching fails closed on every multi-line YAML value it cannot
      represent, and both runtimes agree; the shared contract fixture covers the
      block-scalar case that used to emit invalid YAML.
- [x] Every source-corrupting path found this cycle has a regression that pins
      the bytes: empty-table-cell input, table-cell deletion, slash insertion
      into an existing Block, inline emphasis toggling across span boundaries,
      keyboard edit intent past a closing fence, and code-fence segmentation
      after a list.
- [x] A 16-check and a 5-check probe over the previously reproduced defects both
      pass against the packaged app; all 21 reproduced before the fixes.
- [x] Typing latency is independent of the parse: 20 ms, 46 ms and 148 ms per
      keystroke at 801, 2001 and 8001 Blocks, against 74 ms, 179 ms and 725 ms.
- [x] Public notes preserve the Electron-only, Markdown-only Page and read-only
      Attachment boundary, and record the known limitations rather than implying
      they are fixed.
- [x] A new `v1.10.0` draft contains exactly six signed and notarized candidate
      assets built from the recorded `doXmind-app` source commit.
- [x] The committed SHA-256 manifest, GitHub asset digests, stable DMG alias, and
      `latest-mac.yml` version, names, sizes, and SHA-512 values all match.
- [x] The downloaded DMG and update ZIP pass integrity, Developer ID,
      Gatekeeper, notarization ticket, bundle version, architecture, and
      packaged-runtime boundary checks.
- [x] Packaged Electron GUI acceptance passes from the downloaded candidate with
      all 23 checks, including Block interaction, recovery, and local PDF export.
- [x] Page and Attachment recovery checks leave Markdown, source Attachments,
      `.doxmind`, `.bak`, `.lock`, and `.corrupt-*` artifacts byte-identical.
- [x] A signed, installed `1.8.3` to `1.10.0` Squirrel/ShipIt update restarts and
      cold-launches successfully. `1.8.3` is the current public latest; `1.9.0`
      was never built, so it is not on the update path.
- [x] Build provenance above records the exact source commit and six verified
      signed artifact names and hashes.
- [x] The matching website update is ready, and its version label will deploy
      only after the verified release becomes public/latest.
- [x] The immediate release window is confirmed and the fixed latest-download
      alias plus automatic-update metadata are ready to expose the same bytes.

Every unchecked item above requires the signed candidate to exist and be
verified on a Mac against the downloaded bytes. None of them may be ticked from
the source tree alone.

`1.9.0` was prepared but never published: its own checklist still reads
`Pending release validation` and no candidate was ever built for it. Its notes
and checklist stay in the tree as the record of that work, and the Block-editing
changes they describe ship here. Do not build or publish a `v1.9.0` draft.
