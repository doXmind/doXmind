# doXmind 1.10.0 release notes

doXmind 1.10.0 is a correctness release. Every Markdown feature and every Block
interaction was driven on the packaged app and checked against the file on disk,
because that file is the document — not a cache of it. Where the editor was
writing bytes you had not typed, or hiding bytes you had, that is what this
release fixes.

## Your file stops changing behind you

- Editing a Page property no longer breaks the frontmatter. A property whose
  value spans lines — a `|` block, a list, a nested map — used to have its
  continuation lines orphaned under a rewritten key, leaving YAML that nothing
  could parse again.
- Selecting part of a bold or italic run and pressing Bold no longer writes
  unbalanced markers into the file. Where the edit cannot be made without
  rewriting text outside your selection, it now declines instead.
- A character typed immediately after an `_emphasis_` run is no longer
  discarded, and a typed `!` is written as `!` rather than gaining a backslash.
- Typing into an empty table cell writes what you typed. It used to repeat the
  accumulated prefix on every keystroke, so `hello` reached the file as
  `hellohellhelheh`.
- Deleting the last character of a table cell no longer takes the whole Page
  down with it.
- A press with nothing focused no longer lands past a code fence's closing
  delimiter, where it stopped the fence closing and swallowed the rest of the
  Page on reopening.

## Content you could not see

- A code block written after a list now appears. It was parsed into the list
  item above it and rendered as no Block at all — the text was in the file, on
  no row, reachable by no caret.
- Setext headings (`Title` over `====`) are headings: they appear in the
  outline and can be linked to, and their underline is still never rewritten.
- A slash command run on a Block that already has text keeps that text. `/table`
  on a paragraph used to weld the paragraph into a table row that rendered
  nowhere.
- `/equation` produces an equation. Its template used to round-trip as two
  paragraphs, so there was no gesture in the product that made one.
- Column alignment written in a table's delimiter row is actually drawn. The
  cells carried the right alignment and a stylesheet rule out-specified it.
- A collapsed toggle prints its body when you export a Page to PDF.
- `[[Alias]]` links resolve without opening the target Page first.

## Typing in a long Page

Typing latency no longer grows with the document. Per keystroke, measured on the
packaged app:

| Blocks |   File | Before |    Now |
| -----: | -----: | -----: | -----: |
|    801 |  14 KB |  74 ms |  20 ms |
|   2001 |  35 KB | 179 ms |  46 ms |
|   8001 | 144 KB | 725 ms | 148 ms |

The document was being re-parsed from scratch on every render, and every Block
row re-rendered with it. Collections had a separate cost that scaled with the
whole workspace: a Page holding one `doxmind-collection` fence took 865 ms per
evaluation in a 2,000-Page workspace, and now takes 13 ms.

## Commands that do what they look like

- Turn into, Duplicate, Delete and Move from a Block's menu hand the Block back
  with its caret, instead of leaving the editor with nothing focused.
- Undo after duplicating a Block puts the caret on the Block you duplicated,
  not on the one below it, so the next command acts where you are looking.
- An unresolved `[[Wiki Link]]` looks unresolved, says so to a screen reader,
  and tells you the Page does not exist when you click it.
- An external edit to an open Page now shows a conflict you can actually see
  and answer. The banner used to render under the window chrome.
- A workspace containing one file that is not valid UTF-8 still lists every
  other Page, rather than showing an empty sidebar.
- Renaming a Page or folder that differs only in capitalisation works.

## Known limitations

- A toggle does not render a list, table or code fence inside it; the content is
  shown as raw Markdown.
- Inline math (`$x$`), footnotes, reference-style links and definition lists
  remain exact raw Markdown rather than rendered Blocks.
- Setext headings are recognised as headings by the editor, but not yet by the
  outline label, the document outline command, or heading embeds.
- The Chinese message bundle is complete but unreachable: there is no language
  setting, and the Block editor's own strings are not translated.
