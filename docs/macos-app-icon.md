# macOS app icon sizing

The desktop icon source is generated by `scripts/build-app-icon.mjs` into
`src-tauri/app-icon.png`, then expanded into the Tauri icon set with
`npm run icons`.

For current macOS Dock/Finder rendering, keep the primary rounded-square
enclosure inside the 1024 x 1024 source canvas instead of filling the canvas.
The generated icon uses:

- 1024 x 1024 transparent source canvas
- 832 x 832 black enclosure
- 96 px transparent padding on each side
- subtle baked shadow and edge highlight for legacy `.icns` rendering

Apple's current guidance is moving toward Icon Composer and the layered `.icon`
format for Liquid Glass app icons. Tauri's macOS bundle path still consumes
`icon.icns`, so this project keeps a carefully padded `.icns` source until the
desktop packaging pipeline can adopt `.icon` directly.
