# Keyboard Shortcuts: 10x Your Efficiency

The fastest writers rarely reach for the mouse. Keyboard shortcuts keep your hands on the keys and your mind on your writing, eliminating the small interruptions that add up to significant time loss over a working session. doXmind is designed to be keyboard-first -- nearly every action has a shortcut, and learning even a dozen of them will noticeably speed up your workflow.

This guide organizes every doXmind keyboard shortcut by category, from essential everyday commands to power-user techniques. You do not need to memorize them all at once. Start with the essentials, then add new shortcuts gradually as they become relevant to your work.

## How Shortcuts Are Listed

Throughout this guide, shortcuts are listed in the format `Ctrl+Key` for Windows and Linux, with the Mac equivalent `Cmd+Key` noted where it differs. In most cases, replace `Ctrl` with `Cmd` on Mac.

Modifier key reference:

| Symbol | Windows/Linux | Mac |
|--------|--------------|-----|
| Ctrl | Ctrl key | Cmd key |
| Alt | Alt key | Option key |
| Shift | Shift key | Shift key |

## Essential Shortcuts

These are the shortcuts every doXmind user should know. They cover the actions you perform dozens of times per session.

### Text Formatting

| Shortcut | Action |
|----------|--------|
| `Ctrl+B` | **Bold** selected text |
| `Ctrl+I` | *Italicize* selected text |
| `Ctrl+U` | Underline selected text |
| `Ctrl+Shift+X` | ~~Strikethrough~~ selected text |
| `Ctrl+E` | Inline code formatting |
| `Ctrl+Shift+H` | Highlight selected text |
| `Ctrl+K` | Create or edit hyperlink |

### Basic Editing

| Shortcut | Action |
|----------|--------|
| `Ctrl+Z` | Undo last action |
| `Ctrl+Shift+Z` | Redo last undone action |
| `Ctrl+A` | Select all content |
| `Ctrl+C` | Copy selection |
| `Ctrl+X` | Cut selection |
| `Ctrl+V` | Paste |
| `Ctrl+Shift+V` | Paste without formatting |

Paste without formatting (`Ctrl+Shift+V`) is especially useful when copying text from websites or other applications. It strips all formatting and pastes only the plain text, which you can then format using doXmind's styles.

### Save and Export

| Shortcut | Action |
|----------|--------|
| `Ctrl+S` | Save document |
| `Ctrl+Shift+E` | Export document |

## Navigation Shortcuts

Moving efficiently through your document is just as important as typing quickly. These shortcuts help you navigate without scrolling.

### Document Navigation

| Shortcut | Action |
|----------|--------|
| `Ctrl+Home` | Jump to beginning of document |
| `Ctrl+End` | Jump to end of document |
| `Ctrl+Up` | Move to previous paragraph |
| `Ctrl+Down` | Move to next paragraph |
| `Home` | Move to beginning of line |
| `End` | Move to end of line |
| `Page Up` | Scroll up one page |
| `Page Down` | Scroll down one page |

### Search and Replace

| Shortcut | Action |
|----------|--------|
| `Ctrl+F` | Open search bar |
| `Ctrl+H` | Open search and replace |
| `Enter` | Find next match (when search is open) |
| `Shift+Enter` | Find previous match (when search is open) |
| `Escape` | Close search bar |

Search supports regular expressions for advanced pattern matching. Toggle the regex option in the search bar to enable it.

### Outline Navigation

| Shortcut | Action |
|----------|--------|
| `Ctrl+Shift+O` | Toggle outline panel |

The outline panel shows your document's heading structure. Click any heading to jump directly to that section. This is indispensable for documents longer than a few hundred words.

## Block and Structure Shortcuts

These shortcuts let you create and manipulate content blocks without leaving the keyboard.

### Headings

| Shortcut | Action |
|----------|--------|
| `Ctrl+Alt+1` | Heading 1 |
| `Ctrl+Alt+2` | Heading 2 |
| `Ctrl+Alt+3` | Heading 3 |
| `Ctrl+Alt+4` | Heading 4 |
| `Ctrl+Alt+0` | Normal paragraph |

You can also type heading markers at the beginning of a line using markdown syntax: `# ` for H1, `## ` for H2, `### ` for H3, and so on. doXmind converts them automatically.

### Lists

| Shortcut | Action |
|----------|--------|
| `Ctrl+Shift+7` | Toggle numbered list |
| `Ctrl+Shift+8` | Toggle bullet list |
| `Ctrl+Shift+9` | Toggle checklist (to-do list) |
| `Tab` | Indent list item (increase nesting) |
| `Shift+Tab` | Outdent list item (decrease nesting) |
| `Enter` | New list item |
| `Shift+Enter` | New line within the same list item |

### Block Types

| Shortcut | Action |
|----------|--------|
| `Ctrl+Shift+C` | Insert code block |
| `Ctrl+Shift+B` | Insert blockquote |
| `Ctrl+Shift+D` | Insert divider (horizontal rule) |
| `/` | Open slash command menu |

The slash command menu (`/`) is your gateway to every block type doXmind supports. Type `/` at the beginning of a line, then start typing the block name to filter the options. For example, `/call` quickly narrows to "Callout Block."

### Block Manipulation

| Shortcut | Action |
|----------|--------|
| `Ctrl+Shift+Up` | Move current block up |
| `Ctrl+Shift+Down` | Move current block down |
| `Ctrl+D` | Duplicate current block |
| `Ctrl+Shift+Delete` | Delete current block |

Moving blocks with keyboard shortcuts is far faster than drag-and-drop for quick reordering. Combine with heading shortcuts to restructure entire sections.

## AI Feature Shortcuts

doXmind's AI features are accessible through keyboard shortcuts, so you can invoke assistance without breaking your writing flow.

### Chat and AI Assistance

| Shortcut | Action |
|----------|--------|
| `Ctrl+L` | Open/focus AI chat panel |
| `Ctrl+J` | Quick AI edit on selected text |
| `Escape` | Close AI panel or dismiss suggestion |

### Quick Edit Workflow

The `Ctrl+J` shortcut is one of the most powerful in doXmind. Here is how to use it:

1. Select the text you want to edit.
2. Press `Ctrl+J` to open the quick edit prompt.
3. Type your instruction (e.g., "make this more concise" or "fix grammar").
4. Press `Enter` to submit.
5. Review the diff. Press `Enter` to accept or `Escape` to reject.

This entire sequence takes seconds and keeps your hands on the keyboard throughout.

### Autocomplete

| Shortcut | Action |
|----------|--------|
| `Tab` | Accept autocomplete suggestion |
| `Escape` | Dismiss autocomplete suggestion |

When doXmind AI offers an autocomplete suggestion (shown as ghosted text ahead of your cursor), press `Tab` to accept it or `Escape` to dismiss it and continue writing your own text.

| Shortcut | Action |
|----------|--------|

## Markdown Shortcuts

doXmind supports markdown-style shortcuts that convert as you type. These are not traditional keyboard shortcuts but rather text patterns that the editor recognizes and transforms.

| You Type | doXmind Creates |
|----------|----------------|
| `# ` | Heading 1 |
| `## ` | Heading 2 |
| `### ` | Heading 3 |
| `- ` or `* ` | Bullet list |
| `1. ` | Numbered list |
| `[] ` | Checklist item |
| `> ` | Blockquote |
| `` ``` `` | Code block |
| `---` | Horizontal divider |
| `**text**` | **Bold text** |
| `*text*` | *Italic text* |
| `` `text` `` | `Inline code` |
| `~~text~~` | ~~Strikethrough~~ |

These markdown shortcuts are particularly valuable for writers coming from markdown editors. They let you format text without reaching for modifier keys.

## Building Your Shortcut Vocabulary

Trying to learn all these shortcuts at once is counterproductive. Instead, adopt them gradually using this proven method:

### The Three-Shortcut Rule

Each week, choose three new shortcuts to learn. Write them on a sticky note and place it next to your monitor. Every time you reach for the mouse to perform one of those actions, stop and use the shortcut instead. By the end of the week, the shortcuts will be automatic.

### Start With High-Frequency Actions

Identify the actions you perform most often and learn those shortcuts first. For most writers, the highest-impact shortcuts are:

1. `Ctrl+B` / `Ctrl+I` -- Bold and italic (you probably already know these).
2. `Ctrl+K` -- Hyperlinks.
3. `Ctrl+J` -- Quick AI edit.
4. `Ctrl+L` -- AI chat.
5. `/` -- Slash command menu.
6. `Ctrl+Shift+V` -- Paste without formatting.
7. `Ctrl+F` -- Search.
8. `Ctrl+Shift+O` -- Outline panel.

These eight shortcuts cover the vast majority of actions a writer needs beyond basic typing.

### Practice in Low-Stakes Situations

When you are writing something casual -- a journal entry, meeting notes, a rough brainstorm -- make it a practice session for new shortcuts. The low stakes reduce frustration when muscle memory has not formed yet.

## Next Steps

Keyboard efficiency is a compounding investment -- the time you spend learning shortcuts pays dividends in every future writing session.

- **Pick three shortcuts** from this guide that you do not currently use and commit to using them this week.
- **Try focus mode** (`Ctrl+Shift+\`) for your next writing session. Combined with keyboard shortcuts, it creates an uninterrupted writing flow.
- **Practice the quick AI edit workflow** (`Ctrl+J`) on a few paragraphs. Once this shortcut becomes second nature, you will find yourself using AI assistance far more fluidly.
- **Print the quick reference card** and keep it visible until the shortcuts become automatic. Most writers internalize the core shortcuts within two to three weeks of consistent practice.
