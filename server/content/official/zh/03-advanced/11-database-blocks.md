# 数据库模块：在文档中嵌入结构化数据

写作不只是文字。项目管理、资料整理、读书笔记……许多场景需要在文档中管理结构化数据。doXmind 的数据库模块让你无需离开编辑器，就能创建表格、看板、画廊等多种数据视图，把文档变成一个功能完整的信息管理中心。

## 什么是数据库模块

数据库模块是嵌入文档中的结构化数据容器。与普通的 Markdown 表格不同，它支持：

- **多种视图：** 同一份数据可以用表格、看板、画廊等不同方式展示
- **丰富的字段类型：** 文本、数字、日期、单选、多选、复选框、链接等
- **筛选与排序：** 按条件过滤和排列数据，快速找到需要的信息
- **内置模板：** 常见场景开箱即用，无需从零配置

## 创建你的第一个数据库

### 快速创建

在编辑器中，有两种方式插入数据库模块：

1. **斜杠命令：** 输入 `/database` 或 `/数据库`，从弹出菜单中选择
2. **从模板创建：** 输入 `/database`，在面板中选择一个预设模板

### 选择视图类型

创建时你需要选择一个默认视图：

**表格视图** —— 最经典的行列结构，适合需要精确对比和批量编辑的场景。每一行是一条记录，每一列是一个属性字段。

**看板视图** —— 按某个分类字段将数据分组为列，适合管理有明确阶段的流程。例如按"待办 / 进行中 / 已完成"分组展示任务。

**画廊视图** —— 以卡片形式展示数据，每条记录是一张视觉化的卡片。适合管理有封面图片的内容，如读书清单、产品目录。

## 内置模板详解

doXmind 提供了多个精心设计的数据库模板，覆盖最常见的使用场景。

### 任务管理模板

适用于个人或小团队的任务跟踪。

| 字段 | 类型 | 说明 |
|------|------|------|
| 任务名称 | 文本 | 任务的简短描述 |
| 状态 | 单选 | 待办 / 进行中 / 已完成 |
| 优先级 | 单选 | 高 / 中 / 低 |
| 截止日期 | 日期 | 任务的最后期限 |
| 负责人 | 文本 | 任务的执行者 |

默认提供表格视图和看板视图（按状态分组），你可以根据需要切换。

### 项目管理模板

适用于需要追踪多个项目进度的场景。相比任务模板，增加了"项目阶段""进度百分比""关联文档"等字段，适合更复杂的项目管理需求。

### 阅读清单模板

为读书爱好者设计，包含以下字段：

- **书名** 和 **作者** —— 基本信息
- **类别** —— 小说、商业、技术、历史等多选标签
- **阅读状态** —— 想读 / 在读 / 已读
- **评分** —— 1-5 星评级
- **笔记** —— 读后感和关键摘录

画廊视图下，每本书以封面卡片的形式展示，一目了然。

### 联系人模板

管理人脉和联系信息。包含姓名、公司、职位、邮箱、电话、标签等字段，支持按公司或标签分组筛选。

## 自定义字段与配置

除了使用模板，你也可以从空白数据库开始，完全自定义。

### 添加字段

点击表头右侧的"+"号，选择字段类型：

- **文本：** 自由输入的文字内容
- **数字：** 支持求和、平均值等汇总计算
- **单选：** 从预设选项中选择一个值，适合状态、分类等场景
- **多选：** 可选择多个标签，适合打标签的场景
- **日期：** 支持日期选择器，可设置提醒
- **复选框：** 简单的是/否切换
- **链接：** 存储 URL 地址

### 筛选与排序

点击数据库顶部的筛选图标，可以设置条件：

- 例如：`状态 = 进行中` 且 `优先级 = 高`，快速找到需要立即处理的任务
- 排序支持多级：先按优先级降序，再按截止日期升序

## 在文档中灵活使用

数据库模块的强大之处在于它与文档内容无缝融合。

### 实际应用场景

**项目文档中嵌入任务表。** 在项目方案文档的末尾，插入一个任务管理数据库，将文档与执行跟踪合为一体。

**研究笔记中嵌入文献表。** 写论文或研究报告时，在文档中维护一个参考文献数据库，每条记录链接到原始资料。

**周报中嵌入本周成果。** 在周报模板中内嵌一个数据库，记录每周的关键产出和指标变化。

### 与 AI 协作

你还可以让 doXmind AI 帮助管理数据库中的内容。例如在聊天面板中：

> "根据文档中提到的行动事项，帮我整理成任务列表。"

AI 会分析文档内容，提取其中的行动项，帮你快速填充任务数据库。
