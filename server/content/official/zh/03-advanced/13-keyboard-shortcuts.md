# 键盘快捷键速查：提升 10 倍效率

熟练使用键盘快捷键的人和只用鼠标的人之间，效率差距可以达到数倍。本文整理了 doXmind 中最实用的快捷键，按使用场景分类，从入门到进阶逐步掌握。建议先收藏本文，需要时随时查阅。

> 本文以 Windows/Linux 快捷键为主标注，macOS 用户请将 `Ctrl` 替换为 `Cmd`，将 `Alt` 替换为 `Option`。

## 基础编辑

这些是日常写作中使用频率最高的快捷键。

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + B` | 加粗 |
| `Ctrl + I` | 斜体 |
| `Ctrl + U` | 下划线 |
| `Ctrl + Shift + X` | 删除线 |
| `Ctrl + E` | 行内代码 |
| `Ctrl + Z` | 撤销 |
| `Ctrl + Shift + Z` | 重做 |
| `Ctrl + A` | 全选 |
| `Ctrl + C` | 复制 |
| `Ctrl + V` | 粘贴 |
| `Ctrl + Shift + V` | 纯文本粘贴（去除格式） |

**实用提示：** 纯文本粘贴（`Ctrl + Shift + V`）在从网页或其他文档复制内容时特别有用，可以避免引入混乱的格式。

## 块级格式

快速将当前段落转换为不同的块级元素。

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + Alt + 1` | 转为一级标题（H1） |
| `Ctrl + Alt + 2` | 转为二级标题（H2） |
| `Ctrl + Alt + 3` | 转为三级标题（H3） |
| `Ctrl + Alt + 0` | 转为正文段落 |
| `Ctrl + Shift + 7` | 有序列表 |
| `Ctrl + Shift + 8` | 无序列表 |
| `Ctrl + Shift + 9` | 待办清单 |
| `Ctrl + Shift + B` | 引用块 |
| `Ctrl + Alt + C` | 代码块 |
| `Tab` | 增加列表缩进 |
| `Shift + Tab` | 减少列表缩进 |

**实用提示：** 在空行输入 `/` 可以唤出斜杠命令菜单，用搜索的方式插入任何块级元素，无需记忆所有快捷键。

## 文本选择与光标移动

高效的文本选择是快速编辑的基础。

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + ←/→` | 按词移动光标 |
| `Home` / `End` | 移动到行首/行尾 |
| `Ctrl + Home` | 移动到文档开头 |
| `Ctrl + End` | 移动到文档结尾 |
| `Shift + ←/→` | 按字符选择文本 |
| `Ctrl + Shift + ←/→` | 按词选择文本 |
| `Shift + Home/End` | 选择到行首/行尾 |
| `Ctrl + Shift + Home/End` | 选择到文档开头/结尾 |

**进阶技巧：** 双击选中一个词，三击选中整个段落。这是最快的文本选择方式之一。

## AI 功能快捷键

这些快捷键让你在写作过程中快速调用 doXmind AI 的能力。

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + L` | 打开/关闭 AI 聊天面板 |
| `Ctrl + K` | 对选中文本进行快捷编辑 |
| `Ctrl + J` | 触发 AI 自动补全 |
| `Tab` | 接受 AI 补全建议 |
| `Esc` | 拒绝 AI 补全建议 |
| `Ctrl + Shift + Enter` | 在聊天面板中发送消息 |

### AI 快捷编辑的使用流程

1. 选中需要修改的文本
2. 按 `Ctrl + K` 打开快捷编辑栏
3. 输入你的修改指令（如"简化这段""改为正式语气"）
4. 按 `Enter` 执行
5. 在差异视图中按 `Ctrl + Enter` 接受修改，或按 `Esc` 取消

## 导航与搜索

在长文档中快速定位是一项关键能力。

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + F` | 文档内搜索 |
| `Ctrl + H` | 搜索并替换 |
| `Ctrl + G` | 跳转到指定行 |
| `Ctrl + P` | 快速文件切换 |
| `Enter` / `Shift + Enter` | 搜索时跳到下一个/上一个匹配 |

**实用提示：** `Ctrl + P` 是一个强大的导航工具。在文件列表中输入关键词，可以快速跳转到任何文档，无需在侧边栏中手动查找。

## 视图与面板

控制编辑器界面布局。

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + \` | 切换侧边栏显示/隐藏 |
| `Ctrl + L` | 切换 AI 聊天面板 |
| `Ctrl + Shift + O` | 切换大纲视图 |
| `F11` | 全屏 / 退出全屏 |
| `Ctrl + +` | 放大编辑器字体 |
| `Ctrl + -` | 缩小编辑器字体 |
| `Ctrl + 0` | 重置字体大小 |

## 文件操作

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + N` | 新建文档 |
| `Ctrl + S` | 手动保存（通常自动保存即可） |
| `Ctrl + Shift + S` | 导出文档 |
| `Ctrl + W` | 关闭当前文档 |

## 高效组合技

以下是一些实际写作场景中的快捷键组合使用方式，展示如何将多个快捷键串联起来完成复杂操作。

### 场景一：快速重构段落

1. 三击选中整个段落
2. `Ctrl + K` 打开快捷编辑
3. 输入"拆分为 3 个更短的段落"
4. `Ctrl + Enter` 接受修改

全程无需触碰鼠标，5 秒内完成。

### 场景二：批量调整标题层级

1. `Ctrl + Shift + O` 打开大纲视图
2. 在大纲中拖拽调整章节顺序
3. 选中需要降级的标题，`Ctrl + Alt + 3` 将 H2 改为 H3

### 场景三：写作中快速查资料

1. 写到需要补充信息的地方，按 `Ctrl + L` 打开聊天面板
2. 向 doXmind AI 提问获取信息
3. 将有用的内容复制到正文
4. `Ctrl + L` 关闭面板，继续写作

## 记忆技巧

不需要一次记住所有快捷键。推荐的学习策略：

**第一周：** 掌握基础编辑（加粗、撤销、复制粘贴）和 AI 功能（`Ctrl + L`、`Ctrl + K`）

**第二周：** 学会块级格式（标题、列表）和搜索导航（`Ctrl + F`、`Ctrl + P`）

**第三周：** 练习文本选择技巧和视图切换

**持续：** 每当你发现自己重复使用鼠标完成某个操作时，查一下是否有对应的快捷键
