# Import — multi-router pipeline (replaces markitdown)
#   PDF (native text)  → pymupdf4llm  (fast path, milliseconds, no models)
#   PDF (scanned/dense) → marker-pdf   (Surya layout + OCR; downloads ~2GB on first use)
#   DOCX               → mammoth      (clean docx → HTML)
#   PPTX               → python-pptx  (slide-by-slide markdown emitter)
#
# All four are kept lightweight enough for `pip install` in dev. Marker pulls
