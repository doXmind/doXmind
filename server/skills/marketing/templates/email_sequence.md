## Subject Line Swipe File

### Curiosity
- "This changed everything for me..."
- "I was wrong about [topic]"
- "[Name], I have a question"
- "The one thing [successful people] do differently"

### Benefit
- "Get [result] in [timeframe]"
- "How to [achieve goal] without [pain point]"
- "[Number] ways to [benefit]"
- "Your shortcut to [desired outcome]"

### Social Proof
- "[Number] people already [took action]"
- "How [Name] [achieved result]"
- "Real results from real people"

### Urgency
- "[Time] left to [claim offer]"
- "Closing tonight"
- "Last chance: [offer]"
- "Don't miss this"

### Personal
- "Quick question, [Name]"
- "Can I ask you something?"
- "A personal note"
- "You're invited"

## Email Checklist

For each email:

- [ ] Subject line is compelling (A/B test options)
- [ ] Preview text adds value
- [ ] Opening hooks reader
- [ ] One main message per email
- [ ] One CTA per email
- [ ] CTA is clear and clickable
- [ ] Personal tone (use "you")
- [ ] P.S. line utilized
- [ ] Links work correctly
- [ ] Mobile-friendly formatting
- [ ] Unsubscribe link included
