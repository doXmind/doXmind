## Contextual Onboarding (In-Product)

### First-Time Feature Hints

**Pattern**: Tooltips that appear on first encounter

```
[Tooltip pointing to element]

[Headline]: [Feature Name]

[Body]: [One sentence about what it does and why it's useful]

[CTA]: Got it / Try it
[Dismiss]: ✕
```

### Empty State Onboarding

**Pattern**: Guidance when user encounters empty area

```
[Illustration]

[Headline]: No [items] yet

[Body]: [Brief explanation of what goes here]

[CTA]: Create your first [item]
[Learn More]: How [items] work →
```

### Progressive Disclosure

**Pattern**: Reveal advanced features after basics mastered

```
[Notification or modal]

[Headline]: Ready for more?

[Body]: Now that you've [accomplished basic task], you might want to try [advanced feature].

[CTA]: Show me how
[Dismiss]: Maybe later
```

## Writing Tips for Onboarding

### Do
- Lead with benefits, not features
- Keep each step focused on one action
- Celebrate small wins
- Allow skipping (but track it)
- Use progressive disclosure
- Make it feel fast

### Don't
- Ask for too much information upfront
- Force users through everything
- Use jargon or internal terms
- Make users feel lost or overwhelmed
- Forget about edge cases
