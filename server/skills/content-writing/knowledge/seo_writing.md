# SEO Writing Guide

## Core Principles

SEO writing balances two goals:
1. **Search engine visibility** - Helping Google understand and rank your content
2. **Reader value** - Creating genuinely useful content that satisfies search intent

**The golden rule**: Write for humans first, optimize for search engines second.

---

## Understanding Search Intent

### The 4 Types of Search Intent

| Intent Type | User Goal | Content Format | Example Query |
|-------------|-----------|----------------|---------------|
| **Informational** | Learn something | Blog posts, guides, tutorials | "how to write a blog post" |
| **Navigational** | Find a specific site/page | Landing pages, homepages | "hubspot blog" |
| **Commercial** | Research before buying | Comparisons, reviews, lists | "best email marketing tools" |
| **Transactional** | Complete an action | Product pages, sign-up pages | "buy mailchimp subscription" |

### Matching Intent

Before writing, search your target keyword and analyze:
- What type of content ranks? (lists, guides, videos, tools)
- What's the common format? (word count, structure, depth)
- What questions are being answered?
- What's missing from existing results?

## Keyword Strategy

### Keyword Research Basics

**Primary Keyword**: The main term you want to rank for
- Include in: Title, H1, first 100 words, URL, meta description

**Secondary Keywords**: Related terms and variations
- Include naturally throughout the content
- Use in H2/H3 subheadings

**Long-tail Keywords**: Specific phrases (3+ words)
- Lower competition, higher conversion intent
- Great for FAQ sections and subheadings

### Keyword Placement Checklist

| Location | Priority | Best Practice |
|----------|----------|---------------|
| Title tag | Critical | Front-load keyword, under 60 chars |
| H1 heading | Critical | Match or closely relate to title |
| URL slug | High | Short, keyword-rich, hyphen-separated |
| First 100 words | High | Natural inclusion |
| Meta description | High | Compelling, under 160 chars |
| H2/H3 headings | Medium | Include variations naturally |
| Image alt text | Medium | Descriptive, keyword where relevant |
| Throughout body | Medium | Natural density (no stuffing) |

### Keyword Density

- **Avoid**: Exact keyword repetition that feels unnatural
- **Target**: 1-2% keyword density is a rough guide, not a rule
- **Focus on**: Topic coverage and semantic relevance

## Content Structure for SEO

### Title Tag Optimization

```
Format: [Primary Keyword] - [Benefit/Modifier] | [Brand]
Length: 50-60 characters
```

**Examples:**
- ✅ "How to Write a Blog Post: A Step-by-Step Guide | HubSpot"
- ✅ "15 Email Marketing Tips to Boost Open Rates (2024)"
- ❌ "Blog Writing | Writing Tips | How to Write | Content Marketing" (keyword stuffing)

### Meta Description

```
Length: 150-160 characters
Include: Primary keyword, value proposition, call-to-action
```

**Formula:**
```
[What the content covers] + [Key benefit] + [CTA or hook]
```

**Example:**
```
Learn how to write SEO-friendly blog posts that rank on Google.
Step-by-step guide with templates and real examples. Start ranking today.
```

### URL Structure

**Best Practices:**
- Keep it short (3-5 words)
- Include primary keyword
- Use hyphens, not underscores
- Avoid numbers that will change (e.g., "2024")
- Remove stop words (a, the, and, of)

**Examples:**
- ✅ `/seo-writing-guide`
- ✅ `/blog-post-template`
- ❌ `/the-ultimate-guide-to-writing-seo-optimized-blog-posts-in-2024`

### Heading Hierarchy

```
H1: Main title (one per page)
├── H2: Major sections
│   ├── H3: Subsections
│   │   └── H4: Details (rarely needed)
│   └── H3: Subsections
└── H2: Major sections
```

**H2 Guidelines:**
- One H2 every 200-300 words
- Include keyword variations
- Make them scannable and descriptive

## On-Page SEO Elements

### Internal Linking

**Why it matters:**
- Distributes page authority
- Helps users discover related content
- Improves crawlability

**Best Practices:**
- Link to relevant, high-value pages
- Use descriptive anchor text (not "click here")
- Include 2-5 internal links per 1000 words
- Link from high-authority pages to new content

### External Linking

**Best Practices:**
- Link to authoritative, relevant sources
- 1-3 external links per article
- Opens in new tab for user experience
- Supports claims with credible sources

### Image Optimization

| Element | Best Practice |
|---------|---------------|
| File name | `keyword-descriptive-name.jpg` |
| Alt text | Describe image + include keyword if natural |
| File size | Compress to under 100KB when possible |
| Format | WebP > JPEG > PNG for photos |

**Alt Text Examples:**
- ✅ "SEO writing checklist showing keyword placement tips"
- ✅ "Woman typing on laptop writing a blog post"
- ❌ "image1.jpg"
- ❌ "seo seo writing seo tips seo keywords" (keyword stuffing)

## Featured Snippet Optimization

### Types of Featured Snippets

1. **Paragraph** - Direct answer (40-50 words)
2. **List** - Numbered or bulleted steps
3. **Table** - Comparison data
4. **Video** - YouTube embeds

### How to Optimize for Snippets

**For Paragraph Snippets:**
```
Structure your answer like this:

Q: [Question as H2]
A: [Direct answer in 40-50 words, starting with the key term]

Example:
## What is SEO writing?
SEO writing is the practice of creating content optimized for
search engines while remaining valuable to readers. It involves
strategic keyword placement, proper formatting, and matching
user search intent to improve organic search rankings.
```

**For List Snippets:**
```
## How to [do something]: [Number] Steps

1. [Step 1]
2. [Step 2]
3. [Step 3]
...
```

**For Table Snippets:**
```
Use markdown tables with clear headers:

| Feature | Option A | Option B |
|---------|----------|----------|
| Price   | $10      | $20      |
| Speed   | Fast     | Faster   |
```

## Content Quality Signals

### E-E-A-T Framework

Google evaluates content based on:

- **Experience**: First-hand experience with the topic
- **Expertise**: Demonstrated knowledge and skill
- **Authoritativeness**: Recognized as a go-to source
- **Trustworthiness**: Accurate, honest, safe content

**How to demonstrate E-E-A-T:**
- Include author bios with credentials
- Cite reputable sources
- Keep content updated
- Share personal experiences and case studies
- Include original research or data

### Content Freshness

- Update content annually (or more for fast-changing topics)
- Add new sections, examples, or data
- Update the publication date when making significant changes
- Remove outdated information

## Technical SEO Basics

### Page Speed

- Compress images
- Minimize code
- Use caching
- Choose fast hosting
- Target: Under 3 seconds load time

### Mobile-First

- Responsive design
- Readable font sizes (16px+)
- Tappable buttons (44px+ height)
- No horizontal scrolling

### Core Web Vitals

| Metric | Target | Measures |
|--------|--------|----------|
| LCP (Largest Contentful Paint) | < 2.5s | Loading performance |
| INP (Interaction to Next Paint) | < 200ms | Interactivity |
| CLS (Cumulative Layout Shift) | < 0.1 | Visual stability |

## SEO Writing Checklist

### Before Writing
- [ ] Researched target keyword and search intent
- [ ] Analyzed top-ranking competitors
- [ ] Outlined content structure
- [ ] Identified internal linking opportunities

### While Writing
- [ ] Primary keyword in H1 and first 100 words
- [ ] Secondary keywords in H2s and body
- [ ] Short paragraphs (2-4 sentences)
- [ ] Subheadings every 200-300 words
- [ ] Bullet points and numbered lists
- [ ] One clear topic per section

### After Writing
- [ ] Title tag optimized (50-60 chars)
- [ ] Meta description written (150-160 chars)
- [ ] URL is short and keyword-rich
- [ ] Images have alt text
- [ ] Internal links added (2-5)
- [ ] External links to authoritative sources
- [ ] Checked for featured snippet opportunities
- [ ] Mobile preview reviewed
