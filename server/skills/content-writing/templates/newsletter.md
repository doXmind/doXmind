## Subject Line Formulas

### High-Performing Patterns

```
1. Question Format
   "Have you tried [new approach]?"
   "What if [desired outcome] was easier?"

2. Number + Benefit
   "3 ways to [achieve goal] faster"
   "5 mistakes killing your [metric]"

3. Curiosity Gap
   "The [topic] secret nobody talks about"
   "Why [common belief] is wrong"

4. Personal + Direct
   "[Name], your [topic] guide is here"
   "I was wrong about [topic]"

5. Urgency (use sparingly)
   "Last chance: [offer] ends tonight"
   "[Hours] left to [action]"

6. Social Proof
   "How [person/company] achieved [result]"
   "[Number] people already [action]"
```

### Subject Line Checklist
- [ ] Under 50 characters (mobile-friendly)
- [ ] Front-loads the key benefit
- [ ] Creates curiosity or promises value
- [ ] Avoids spam trigger words (FREE, ACT NOW, !!!)
- [ ] Matches email content (no clickbait)

---

## Preview Text

**Purpose**: Extends subject line, provides additional context

**Best Practices**:
- Complement, don't repeat the subject line
- Include a secondary hook or benefit
- 40-100 characters ideal

**Examples**:
| Subject Line | Preview Text |
|--------------|--------------|
| "3 writing tips that changed everything" | "Plus: the tool I can't live without" |
| "Your Monday motivation" | "5 minutes to read. 5 days of impact." |
| "We need to talk about [topic]" | "It's not what you think..." |

## Email Body Template

### Header Section

```
[Logo/Brand Image - optional]

[Greeting - personalize if possible]

Hi {first_name},

[Or use a warm, brand-appropriate greeting]
```

### Opening Hook (2-3 sentences)

```
[Start with ONE of these approaches:]

1. Personal Story
   "Last week, something happened that made me rethink..."

2. Surprising Fact
   "Did you know that [statistic]?"

3. Direct Value Statement
   "I'm going to show you exactly how to [desired outcome]."

4. Empathy Lead
   "If you've ever felt [pain point], you're not alone."

5. Question
   "What would change if you could [desired outcome]?"
```

### Main Content

```
[Transition from hook to main content]

Here's the thing:

[Main message - 2-3 short paragraphs]

[Keep paragraphs to 1-3 sentences for easy scanning]

[Use formatting to aid readability:]
• Bullet points for lists
• **Bold** for emphasis
• White space between sections

[If sharing multiple items:]

📌 [Item 1 Title]
[Brief description - 1-2 sentences]

📌 [Item 2 Title]
[Brief description]

📌 [Item 3 Title]
[Brief description]
```

### Call-to-Action

```
[Lead into CTA with clear benefit]

Ready to [achieve outcome]?

        [👉 CTA BUTTON TEXT]

[Optional: Add urgency or reduce friction]
"Takes less than 2 minutes"
"No credit card required"
"Available until [date]"
```

### Closing

```
[Warm sign-off that matches brand voice]

Talk soon,
[Signature]

[Name]
[Title - optional]
[Company]

P.S. [Add a PS for secondary CTA or personal note - highest read section!]
```

## Email Types & Templates

### 1. Value/Educational Email

```
Subject: [Number] ways to [achieve goal]

Hi {first_name},

[Hook: Why this topic matters now]

Here are [number] [tips/strategies/ideas] to help you [outcome]:

1️⃣ [Tip 1]
[Brief explanation]

2️⃣ [Tip 2]
[Brief explanation]

3️⃣ [Tip 3]
[Brief explanation]

[Bonus tip or resource]

Want to dive deeper?

[CTA: Link to full guide/video/resource]

[Sign-off]
```

### 2. Story/Personal Email

```
Subject: [Intriguing personal hook]

Hi {first_name},

[Short personal story - 3-4 sentences]

Here's what I learned:

[Key insight - 2-3 sentences]

[How this applies to the reader]

[Transition to CTA]

[CTA Button]

[Sign-off]

P.S. [Personal note or question to drive replies]
```

### 3. Promotional Email

```
Subject: [Offer] + [Urgency or exclusivity]

Hi {first_name},

[1 sentence hook about the offer]

Here's what you get:

✅ [Benefit 1]
✅ [Benefit 2]
✅ [Benefit 3]

[Social proof: testimonial or result]

[Urgency element if applicable]

[PRIMARY CTA BUTTON]

[Address potential objection]

[Secondary CTA or guarantee]

[Sign-off]
```

### 4. Newsletter Digest

```
Subject: [This week/month] in [topic]

Hi {first_name},

Here's your [weekly/monthly] dose of [topic]:

📰 TOP STORY
[Headline + 2 sentences + link]

📚 WORTH READING
• [Article 1] - [why it's valuable]
• [Article 2] - [why it's valuable]
• [Article 3] - [why it's valuable]

💡 QUICK TIP
[Actionable tip in 2-3 sentences]

🎯 FROM US
[Your latest content/product/announcement]

[CTA Button]

See you next [week/month]!
[Sign-off]
```

## Pre-Send Checklist

### Content
- [ ] Subject line under 50 characters
- [ ] Preview text complements subject
- [ ] One clear CTA (single focus)
- [ ] Copy is scannable (short paragraphs, bullets)
- [ ] Personalization tags work correctly
- [ ] Links are correct and trackable
- [ ] Unsubscribe link is present

### Technical
- [ ] Mobile preview looks good
- [ ] Images have alt text
- [ ] Plain text version is readable
- [ ] Sender name and email are correct
- [ ] Test email sent to self

### Timing
- [ ] Scheduled for optimal send time
- [ ] Not conflicting with other campaigns
- [ ] Timezone considerations addressed
