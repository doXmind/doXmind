# Dialogue Formatting Guide

## Basic Dialogue Format

### Standard Format

```
"Dialogue goes inside quotation marks," she said.
```

### Dialogue Tag Placement

**After dialogue:**
```
"I'll be there by noon," Sarah said.
```

**Before dialogue:**
```
Sarah said, "I'll be there by noon."
```

**In the middle of dialogue:**
```
"I'll be there," Sarah said, "by noon."
```

---

## Punctuation Rules

### With Dialogue Tags

**Comma before tag (not period):**
```
"I'm leaving," he said.
(NOT: "I'm leaving." he said.)
```

**Period after tag:**
```
She whispered, "Be careful."
```

**Question mark stays inside:**
```
"Are you coming?" she asked.
```

**Exclamation mark stays inside:**
```
"Watch out!" he shouted.
```

### Without Dialogue Tags (Action Beats)

**Period after dialogue, period after action:**
```
"I'm leaving." He grabbed his coat.
(NOT: "I'm leaving," he grabbed his coat.)
```

**Use action beats to vary from constant "said":**
```
"I don't believe it." Maria set down her coffee cup.
```

---

## Paragraph Rules

### New Speaker = New Paragraph

```
"I can't believe you did that," Sarah said.

"I had no choice," Tom replied.

"There's always a choice."
```

### Long Speeches

**For extended dialogue, close quotes at end of paragraph, open at beginning of next:**
```
"This is the beginning of a long speech that continues for quite a while.

"Notice there's no closing quote at the end of the previous paragraph, but there's an opening quote here. This helps the reader track that the same person is still speaking.

"And this paragraph finally ends." She paused for breath.
```

## Dialogue Tags

### Best Practices

**"Said" is invisible:**
The word "said" is nearly invisible to readers—use it freely.

**Avoid overusing alternatives:**
- Don't: "I'm tired," she exclaimed, declared, pronounced, articulated
- Do: "I'm tired," she said.

**Use alternatives sparingly for specific purposes:**
- "whispered" - for volume
- "shouted" - for volume
- "asked" - for questions
- "replied" - for responses

### Tags to Avoid

| Avoid | Why | Alternative |
|-------|-----|-------------|
| "hissed" | Can't hiss words without S sounds | "said" + description |
| "laughed" | Can't laugh and speak simultaneously | "said, laughing" |
| "smiled" | Can't smile words | "said with a smile" |
| "grinned" | Same issue | "said, grinning" |

### Better Approach: Action Beats

Instead of creative dialogue tags, use action beats:
```
"I don't think so." She crossed her arms.
"Maybe you're right." He stared out the window.
```

## Formatting Variations

### Interrupted Dialogue

**Using em dash (—):**
```
"I was just going to—"
"I don't want to hear it."
```

**Character interrupts themselves:**
```
"I thought I could—no, never mind."
```

### Trailing Off

**Using ellipsis (...):**
```
"I wanted to tell you that I..."
She looked away.
```

### Emphasis

**Italics for stressed words:**
```
"I never said I would help him."
(emphasizing "never")
```

### Unspoken Thoughts

**Italics without quotes:**
```
She smiled at him. What is he hiding?
"Everything okay?" she asked aloud.
```

**Or with tag:**
```
What is he hiding? she wondered.
```

## Dialogue Without Tags

### When Tags Aren't Needed

**Clear two-person conversation:**
```
"Did you take it?"
"No."
"I don't believe you."
"I don't care."
```

**With action beats for clarity:**
```
Sarah leaned forward. "Did you take it?"
"No."
"I don't believe you."
Tom shrugged. "I don't care."
```

### When Tags Are Needed

- More than two speakers
- Long exchanges where reader might lose track
- To control pacing
- To add characterization

## Special Dialogue Situations

### Dialogue Within Dialogue

**Use single quotes inside double quotes:**
```
"She said, 'I'll never forgive you,' and walked out."
```

### Written Text in Dialogue

```
The note said: "Meet me at midnight."
```

Or italics for letters/text messages:
```
The text read: *Running late. Start without me.*
```

### Foreign Words/Phrases

**Italicize foreign words:**
```
"It's called joie de vivre," she explained.
```

### Accents and Dialect

**Light touch is best:**
```
"Y'all comin' to dinner?"
(Don't overdo phonetic spelling—it becomes hard to read)
```

## Common Mistakes

### Don't

```
"Hello." She said.
(Period should be comma: "Hello," she said.)

"I'm going" said Tom.
(Missing comma: "I'm going," said Tom.)

She said "I'll go."
(Missing comma: She said, "I'll go.")

"Hello, she said."
(Quote marks in wrong place)
```

### Do

```
"Hello," she said.
"I'm going," said Tom.
She said, "I'll go."
"Hello," she said.
```

## Dialogue Formatting Checklist

Before finalizing:

- [ ] New paragraph for each new speaker
- [ ] Punctuation inside quotation marks
- [ ] Commas before dialogue tags
- [ ] Periods with action beats
- [ ] "Said" used appropriately
- [ ] Action beats for variety
- [ ] Italics for unspoken thoughts
- [ ] Em dashes for interruptions
- [ ] Ellipses for trailing off
- [ ] Consistent formatting throughout

## Quick Reference

| Situation | Format |
|-----------|--------|
| Basic dialogue | "Text," she said. |
| Question | "Text?" she asked. |
| Exclamation | "Text!" she said. |
| Action beat | "Text." She walked away. |
| Interrupted | "Text—" |
| Trailing off | "Text..." |
| Thought | *Text* or Text, she thought. |
| Mid-sentence tag | "Text," she said, "more text." |
| Continued speech | No close quote at paragraph end, open quote at next paragraph start |
