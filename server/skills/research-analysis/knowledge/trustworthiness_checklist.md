# Research Trustworthiness & Quality Checklist

This guide covers validity and reliability for quantitative research, and trustworthiness criteria for qualitative research.

---

## Part 1: Quantitative Research Quality

### Validity Types

| Type | Definition | How to Assess |
|------|------------|---------------|
| **Internal Validity** | The extent to which the study establishes a cause-effect relationship | Control for confounding variables, use randomization, blind procedures |
| **External Validity** | The extent to which findings can be generalized | Representative sampling, multiple settings, replication studies |
| **Construct Validity** | The extent to which measures accurately represent the concept | Use validated instruments, pilot testing, expert review |
| **Content Validity** | The extent to which a measure covers all aspects of a concept | Expert panel review, literature-based item development |
| **Face Validity** | Whether the measure appears to measure what it claims | Expert and participant review |
| **Criterion Validity** | How well results correlate with established measures | Concurrent validity (compare with existing measures), predictive validity (predict future outcomes) |

### Reliability Types

| Type | Definition | How to Assess |
|------|------------|---------------|
| **Test-Retest Reliability** | Consistency of results over time | Administer same test to same group at different times; calculate correlation |
| **Inter-Rater Reliability** | Agreement between different raters/observers | Cohen's Kappa, ICC (Intraclass Correlation Coefficient), percentage agreement |
| **Internal Consistency** | How well items within a scale measure the same construct | Cronbach's alpha (acceptable: > 0.70), split-half reliability |
| **Parallel Forms Reliability** | Consistency between equivalent versions of a test | Correlate scores from two equivalent forms |

### Threats to Internal Validity

| Threat | Description | How to Address |
|--------|-------------|----------------|
| **Selection Bias** | Groups differ at baseline | Random assignment, matching, statistical control |
| **History** | External events affect outcomes | Control group, shorter study duration |
| **Maturation** | Natural changes over time | Control group, appropriate time frame |
| **Testing Effect** | Prior testing affects later performance | Control group, alternate forms |
| **Instrumentation** | Changes in measurement over time | Standardized procedures, calibration |
| **Regression to Mean** | Extreme scores tend toward average | Use reliable measures, avoid extreme group selection |
| **Attrition** | Differential dropout | Intent-to-treat analysis, follow-up on dropouts |
| **Diffusion** | Treatment spreads to control group | Physical separation, different sites |

### Threats to External Validity

| Threat | Description | How to Address |
|--------|-------------|----------------|
| **Sample Characteristics** | Sample not representative | Random sampling, diverse recruitment |
| **Setting** | Results specific to study context | Multi-site studies, varied settings |
| **Time** | Results specific to time period | Replication at different times |
| **Reactivity** | Awareness of being studied (Hawthorne effect) | Unobtrusive measures, control group |

## Part 2: Qualitative Research Trustworthiness

Based on Lincoln and Guba's (1985) framework, qualitative research uses different criteria than quantitative research.

### The Four Criteria

| Criterion | Parallel to (Quantitative) | Definition |
|-----------|---------------------------|------------|
| **Credibility** | Internal Validity | Confidence in the truth of findings |
| **Transferability** | External Validity | Applicability to other contexts |
| **Dependability** | Reliability | Consistency and replicability of findings |
| **Confirmability** | Objectivity | Extent to which findings are shaped by participants, not researcher bias |

---

### Credibility Strategies

| Strategy | Description | Checklist |
|----------|-------------|-----------|
| **Prolonged Engagement** | Spending sufficient time in the field | [ ] Spent adequate time with participants |
| | | [ ] Built trust and rapport |
| | | [ ] Learned the culture/context |
| **Persistent Observation** | In-depth focus on relevant elements | [ ] Identified relevant characteristics |
| | | [ ] Focused on most important aspects |
| **Triangulation** | Using multiple sources/methods | [ ] Used multiple data sources |
| | | [ ] Used multiple methods |
| | | [ ] Used multiple investigators |
| | | [ ] Used multiple theories |
| **Peer Debriefing** | Discussion with impartial colleagues | [ ] Regular sessions with peer debriefer |
| | | [ ] Documented debriefing sessions |
| | | [ ] Addressed raised concerns |
| **Negative Case Analysis** | Actively seeking disconfirming evidence | [ ] Looked for contradictory cases |
| | | [ ] Revised hypotheses as needed |
| | | [ ] Explained negative cases |
| **Member Checking** | Verification by participants | [ ] Returned findings to participants |
| | | [ ] Incorporated participant feedback |
| | | [ ] Documented changes made |
| **Reflexivity** | Researcher self-examination | [ ] Maintained reflexive journal |
| | | [ ] Examined own biases and assumptions |
| | | [ ] Documented positionality |

---

### Transferability Strategies

| Strategy | Description | Checklist |
|----------|-------------|-----------|
| **Thick Description** | Rich, detailed account of context | [ ] Described setting in detail |
| | | [ ] Described participants thoroughly |
| | | [ ] Provided context for findings |
| | | [ ] Included direct quotes |
| **Purposive Sampling** | Strategic selection of information-rich cases | [ ] Justified sampling strategy |
| | | [ ] Selected diverse cases |
| | | [ ] Documented selection criteria |

---

### Dependability Strategies

| Strategy | Description | Checklist |
|----------|-------------|-----------|
| **Audit Trail** | Transparent documentation of research process | [ ] Documented raw data |
| | | [ ] Documented data reduction and analysis notes |
| | | [ ] Documented data reconstruction and synthesis products |
| | | [ ] Documented process notes |
| | | [ ] Documented materials relating to intentions and dispositions |
| | | [ ] Documented instrument development information |
| **External Audit** | Review by independent researcher | [ ] Invited external reviewer |
| | | [ ] Provided access to all materials |
| | | [ ] Addressed audit findings |

---

### Confirmability Strategies

| Strategy | Description | Checklist |
|----------|-------------|-----------|
| **Audit Trail** | Documentation showing data-to-conclusions pathway | [ ] Clear chain of evidence |
| | | [ ] Decisions documented and justified |
| **Reflexivity** | Acknowledgment of researcher influence | [ ] Documented researcher positionality |
| | | [ ] Examined influence on research |
| **Triangulation** | Multiple perspectives to confirm findings | [ ] Converging evidence from multiple sources |

## Part 3: Mixed Methods Quality

For mixed methods research, assess both quantitative and qualitative components, plus integration quality.

### Integration Quality Criteria

| Criterion | Description | Checklist |
|-----------|-------------|-----------|
| **Design Quality** | Appropriate mixing of methods | [ ] Clear rationale for mixed methods |
| | | [ ] Appropriate design selected |
| | | [ ] Clear integration points identified |
| **Legitimation** | Validity of combined inferences | [ ] Sample integration addressed |
| | | [ ] Inside-outside perspectives balanced |
| | | [ ] Weakness minimization achieved |
| | | [ ] Sequential legitimation checked |
| | | [ ] Paradigm mixing addressed |
| **Interpretive Rigor** | Quality of meta-inferences | [ ] Findings from both strands integrated |
| | | [ ] Convergence/divergence explained |
| | | [ ] Meta-inferences drawn |

## Part 4: Quick Reference Checklists

### Quantitative Study Quality Checklist

- [ ] Research question clearly stated
- [ ] Appropriate study design for question
- [ ] Sample size justified (power analysis)
- [ ] Random sampling or justified sampling strategy
- [ ] Random assignment (for experiments)
- [ ] Valid and reliable measures used
- [ ] Confounding variables controlled
- [ ] Appropriate statistical analyses
- [ ] Effect sizes reported
- [ ] Limitations acknowledged
- [ ] Results generalizable to target population

### Qualitative Study Quality Checklist

- [ ] Research question appropriate for qualitative inquiry
- [ ] Methodology justified and described
- [ ] Sampling strategy appropriate and described
- [ ] Data collection methods clearly described
- [ ] Researcher positionality acknowledged
- [ ] Data analysis process transparent
- [ ] Findings supported by data (quotes)
- [ ] Credibility strategies employed
- [ ] Transferability addressed (thick description)
- [ ] Dependability demonstrated (audit trail)
- [ ] Confirmability strategies used
- [ ] Limitations acknowledged

### Systematic Review Quality Checklist

- [ ] Review question clearly formulated (PICO/SPIDER)
- [ ] Protocol registered (PROSPERO)
- [ ] Comprehensive search strategy
- [ ] Multiple databases searched
- [ ] Grey literature included
- [ ] Explicit inclusion/exclusion criteria
- [ ] Dual screening process
- [ ] Risk of bias assessment conducted
- [ ] Data extraction systematic
- [ ] Synthesis method appropriate
- [ ] Heterogeneity explored (if meta-analysis)
- [ ] Publication bias assessed
- [ ] PRISMA guidelines followed
- [ ] Certainty of evidence assessed (GRADE)

## Part 5: Common Quality Assessment Tools

### For Different Study Types

| Study Type | Assessment Tool |
|------------|-----------------|
| RCTs | Cochrane Risk of Bias 2 (RoB 2) |
| Non-randomized interventions | ROBINS-I |
| Observational studies | Newcastle-Ottawa Scale (NOS) |
| Diagnostic accuracy | QUADAS-2 |
| Qualitative studies | CASP Qualitative Checklist |
| Case reports | JBI Critical Appraisal Checklist |
| Mixed methods | MMAT (Mixed Methods Appraisal Tool) |
| Systematic reviews | AMSTAR 2 |

### Reporting Guidelines

| Study Type | Guideline |
|------------|-----------|
| RCTs | CONSORT |
| Observational studies | STROBE |
| Systematic reviews | PRISMA |
| Qualitative research | COREQ, SRQR |
| Case reports | CARE |
| Diagnostic accuracy | STARD |
| Economic evaluations | CHEERS |
| Animal research | ARRIVE |
