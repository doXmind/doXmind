# Social Media Content Templates

## Quick Reference

| Platform | Optimal Post Length | Best Practices |
|----------|-------------------|----------------|
| Twitter/X | 70-100 characters | Threads for depth, conversational tone |
| LinkedIn | 1,300-2,000 characters | Professional storytelling, line breaks |
| Instagram | 125-150 characters (before fold) | Visual-first, hashtag strategy |
| Xiaohongshu | Title: 18-20 chars | Emoji-rich, numbered lists |
| WeChat | Title: ≤22 chars | Value-driven, clear structure |

---

## Twitter/X Templates

### Single Tweet - Insight/Tip

```
[Bold claim or insight]

[Supporting detail or proof point]

[Call to action or question]
```

**Example:**
```
Most people write tweets backwards.

They start with the idea, then the hook.

Flip it. Hook first. Idea second.

Your engagement will thank you.
```

### Single Tweet - Contrarian Take

```
Unpopular opinion: [Contrarian statement]

Here's why:

[Reason 1]
[Reason 2]
[Reason 3]

[Soften or invite discussion]
```

### Thread Opener

```
[Number] [topic] that [benefit/outcome]:

(A thread)

🧵👇
```

**Example:**
```
7 writing habits that 10x'd my output:

(A thread)

🧵👇
```

### Thread Structure

```
Tweet 1: Hook + promise
Tweet 2-7: One point per tweet with example
Tweet 8: Summary + CTA
Tweet 9: "If you found this helpful, RT the first tweet"
```

### Caption - Behind the Scenes

```
[Real/raw statement about the journey]

[Blank line]

What you see: [The polished result]
What you don't see: [The messy reality]

[Blank line]

[1-2 sentences with the lesson or insight]

[Blank line]

Double tap if you relate 🙌
```

### Hashtag Strategy

```
Mix of:
- 3-5 niche hashtags (10K-100K posts)
- 2-3 medium hashtags (100K-500K posts)
- 1-2 broad hashtags (500K+ posts)

Place hashtags:
- In caption (looks cleaner)
- OR first comment (keeps caption clean)
```

## 小红书 (Xiaohongshu) Templates

### 标题公式

```
[数字] + [名词] + [效果/结果]
```

**示例:**
- 「5个习惯让我皮肤变好了」
- 「这3招搞定拖延症 亲测有效」
- 「新手必看！xx入门全攻略」

### 正文模板 - 干货分享

```
[标题：18-20字，含关键词和emoji]

✨ [开头一句话点明主题]

—————————

📍 [要点1标题]
[具体内容，2-3句话]

📍 [要点2标题]
[具体内容]

📍 [要点3标题]
[具体内容]

—————————

💡 小tips：[额外补充]

🏷️ 喜欢记得收藏+关注哦～

#话题1 #话题2 #话题3
```

### 正文模板 - 好物推荐

```
[产品名] | [一句话卖点] [emoji]

🌟 使用感受：
[真实体验，1-2句]

✅ 优点：
• [优点1]
• [优点2]
• [优点3]

⚠️ 小缺点：
• [缺点，显得真实]

💰 价格：[价格区间]
📍 购买渠道：[渠道]

—————————

总结：[一句话总评] [打分/5]

#好物分享 #[品类] #[品牌]
```

## 微信公众号 Templates

### 标题公式

```
类型1：数字型
「[数字] + [主题] + [结果]」
例：3个方法，让你的文章阅读量翻倍

类型2：悬念型
「[意外/反常识] + [引发好奇]」
例：为什么越努力的人，越容易失败？

类型3：对比型
「[A] vs [B]：[差异点]」
例：月薪3000和月薪3万的人，差距在哪？

类型4：痛点型
「[目标人群] + [痛点] + [解决方案]」
例：写作新手必看：如何快速找到选题灵感
```

### 文章结构模板

```
【标题】≤22字符

【摘要】50-120字，点明文章价值

—— 正文 ——

## 开头（150字内）
[场景/故事/数据] 引出问题
[明确文章能解决什么问题]

## 正文部分

### 小标题1
[内容，300-500字一个小节]
[配图位置]

### 小标题2
[内容]

### 小标题3
[内容]

## 结尾
[总结核心观点]
[引导互动：点赞/在看/转发]

—————
[作者介绍]
[往期推荐]
```

## Content Calendar Planning

### Weekly Content Mix

| Day | Content Type | Goal |
|-----|--------------|------|
| Mon | Educational/Tips | Value delivery |
| Tue | Behind-the-scenes | Authenticity |
| Wed | User content/Testimonial | Social proof |
| Thu | Industry news/Opinion | Thought leadership |
| Fri | Fun/Engaging | Community building |
| Sat | Promotional | Conversion |
| Sun | Inspirational/Story | Emotional connection |

### Repurposing Framework

```
1 Blog Post →
├── 5-7 Tweet thread
├── 1 LinkedIn carousel
├── 3-5 Instagram posts
├── 1 Newsletter section
└── 1 Xiaohongshu 干货帖
```
