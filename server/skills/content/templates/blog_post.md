## Pre-Publish Checklist

### Content Quality
- [ ] Headline delivers on promise
- [ ] Introduction hooks within first 2 sentences
- [ ] Each section has one clear point
- [ ] Examples or data support claims
- [ ] Conclusion has clear CTA

### SEO
- [ ] Primary keyword in H1, first 100 words, conclusion
- [ ] Secondary keywords distributed naturally
- [ ] Meta description is compelling and under 160 chars
- [ ] Alt text added to all images
- [ ] 2-5 internal links included
- [ ] 1-3 external links to authoritative sources

### Readability
- [ ] Paragraphs are 2-4 sentences
- [ ] Sentences average 15-20 words
- [ ] Grade level 6-8 (use Hemingway app)
- [ ] No jargon without explanation
- [ ] Formatted for mobile scanning
