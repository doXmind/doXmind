# APA 7th Edition Citation Guide

## In-Text Citations

### Basic Format
- One author: (Smith, 2023)
- Two authors: (Smith & Jones, 2023)
- Three or more authors: (Smith et al., 2023)

### Direct Quotes
- Short quote (under 40 words): (Smith, 2023, p. 15)
- Block quote (40+ words): Indent the entire quote, no quotation marks

### Multiple Works
- Same author, different years: (Smith, 2020, 2023)
- Different authors: (Jones, 2021; Smith, 2023)

## Reference List Format

### Books

**Single Author:**
```
Author, A. A. (Year). Title of work: Capital letter also for subtitle. Publisher.
```
Example:
```
Smith, J. D. (2023). Academic writing mastery: A comprehensive guide. Academic Press.
```

**Multiple Authors:**
```
Author, A. A., & Author, B. B. (Year). Title of work. Publisher.
```

**Edited Book:**
```
Editor, E. E. (Ed.). (Year). Title of work. Publisher.
```

### Journal Articles

**Print Journal:**
```
Author, A. A. (Year). Title of article. Journal Name, Volume(Issue), Page–Page.
```
Example:
```
Smith, J. D. (2023). The impact of AI on education. Journal of Educational Technology, 45(2), 123-145.
```

**Online Journal with DOI:**
```
Author, A. A. (Year). Title of article. Journal Name, Volume(Issue), Page–Page. https://doi.org/xxxxx
```

### Websites

**Webpage with Author:**
```
Author, A. A. (Year, Month Day). Title of page. Site Name. URL
```

**Webpage without Author:**
```
Title of page. (Year, Month Day). Site Name. URL
```

### Other Sources

**Conference Paper:**
```
Author, A. A. (Year, Month Day–Day). Title of paper [Paper presentation]. Conference Name, Location.
```

**Thesis/Dissertation:**
```
Author, A. A. (Year). Title of dissertation [Doctoral dissertation, University Name]. Database Name.
```

## Formatting Rules

1. **Hanging Indent**: Second and subsequent lines indented 0.5 inches
2. **Double Spacing**: Entire reference list
3. **Italics**: Book titles, journal names, volume numbers
4. **Capitalization**: Only first word and proper nouns in titles
5. **Alphabetization**: By first author's last name
6. **DOIs**: Include when available, as hyperlinks

## Citing Generative AI (2025 Update)

APA issued updated guidance in September 2025 for citing generative AI. Now that most AI tools allow chats to be shared with unique URLs, authors can cite specific chats.

### Reference Format

```
Company Name. (Year, Month Day). Title of chat [Generative AI chat]. AI Tool Name. URL
```

**Elements:**
- **Author**: The company that develops/owns the AI tool (e.g., OpenAI, Anthropic, Google)
- **Date**: The specific day, month, and year the chat occurred
- **Title**: The title of the chat (if none, use first few words), followed by [Generative AI chat]
- **Source**: The AI tool name (e.g., ChatGPT, Claude, Gemini), followed by the chat URL

### Examples

**ChatGPT:**
```
OpenAI. (2025, January 15). Explaining the PEEL paragraph method [Generative AI chat]. ChatGPT. https://chat.openai.com/share/abc123
```

**Claude:**
```
Anthropic. (2025, January 15). Research methodology comparison [Generative AI chat]. Claude. https://claude.ai/share/xyz789
```

**Gemini:**
```
Google. (2025, January 15). Literature review strategies [Generative AI chat]. Gemini. https://gemini.google.com/share/def456
```

### In-Text Citations

- Parenthetical: (OpenAI, 2025)
- Narrative: OpenAI (2025) suggested that...

### When Chat Cannot Be Shared

If the AI chat cannot be shared via URL, describe the AI tool used in your methodology section instead of creating a reference entry. Include:
- The name and version of the AI tool
- The company that created it
- The date(s) you used it
- A brief description of how it was used

Example in text:
> "We used ChatGPT-4 (OpenAI, 2025) to assist with initial literature searches. All AI-generated content was verified against primary sources."

### Important Considerations

1. **Verify AI outputs**: Always verify information from AI tools against primary sources
2. **Transparency**: Disclose AI use in your methodology or acknowledgments
3. **Institutional policies**: Check your institution's policies on AI use in academic work
4. **Reproducibility**: AI outputs may not be reproducible; document your prompts if needed
5. **Authorship**: AI tools cannot be listed as authors; they are tools, not collaborators

### Other AI Tools

**Image Generators (DALL-E, Midjourney):**
```
OpenAI. (2025, January 15). [AI-generated image of abstract data visualization]. DALL-E 3. https://...
```

**Code Assistants (GitHub Copilot):**
```
GitHub. (2025, January 15). Python function for data analysis [AI-generated code]. GitHub Copilot. https://...
```
