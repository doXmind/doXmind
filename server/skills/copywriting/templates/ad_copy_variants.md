## Facebook/Instagram Ads

### Hook Variants (First Line)

**Direct Benefit**:
"Get [specific result] in [timeframe]"

**Problem Callout**:
"Tired of [pain point]?"

**Curiosity**:
"This [product type] is changing how [audience] [achieve goal]"

**Question**:
"What would you do with an extra [benefit - time, money, etc.]?"

**Bold Claim**:
"[X%] of our customers see [result] within [timeframe]"

### Ad Copy Variant 1: Problem-Agitate-Solution

**Hook**: [Problem callout]

**Body**:
[Agitate the problem - make it feel urgent]

[Introduce solution]

[Key benefit + proof]

**CTA**: [Action phrase]

**Example**:
```
Tired of spending hours on content that nobody reads?

You know the feeling - you pour your heart into a post, hit publish, and... crickets.

Meanwhile, your competitors seem to go viral every time.

What's their secret? It's not luck. It's [Product].

Join 10,000+ creators who've 3x'd their engagement.

Try it free for 14 days.
```

## Google Ads (Search)

### Headline Options (30 characters each)

**Benefit-Focused**:
- "[Benefit] in [Time]"
- "Get [Result] Fast"
- "Save [X%] on [Product]"
- "[Number]+ [People] Trust Us"

**Feature-Focused**:
- "Free [Feature/Offer]"
- "[Year]'s Best [Category]"
- "Award-Winning [Product]"

**Action-Focused**:
- "Try Free for [X] Days"
- "Get Started Today"
- "Claim Your Discount"

### Description Options (90 characters each)

**Description 1**:
"[Main benefit]. [Secondary benefit]. [CTA] - [Trust element]."

**Description 2**:
"[Problem solved]. [How it works briefly]. [Urgency/offer]."

### Complete Ad Examples

**Ad Variant 1**:
```
Headline 1: [Benefit] in [Timeframe]
Headline 2: Trusted by [Number]+ [People]
Headline 3: Free Trial Available
Description 1: [Main benefit sentence]. [Secondary benefit]. Start today.
Description 2: No credit card required. [Feature]. [Guarantee].
```

**Ad Variant 2**:
```
Headline 1: [Year]'s #1 [Category]
Headline 2: [X]% Off This Week Only
Headline 3: [Star Rating] Star Reviews
Description 1: [Problem you solve]. [Key differentiator]. Limited time offer.
Description 2: [Specific result customers get]. Try risk-free. Cancel anytime.
```

### Headline Variants (150 characters)

**Professional Benefit**:
"[Job Title]s: Get [Professional Result] with [Product]"

**Industry Insight**:
"How Top [Industry] Companies [Achieve Result]"

**Data-Driven**:
"[Number]% of [Industry] Leaders Use [This Strategy]"

### Body Copy Variants

**Variant 1: Professional Challenge**
```
[Industry] professionals face a tough challenge: [problem statement].

The result? [Negative consequences].

[Product/Solution] changes that.

[Specific benefit for professionals]

[Company] and [Company] already see results.

[CTA]
```

```
After working with [number]+ [companies/professionals], we discovered:

The difference between [average result] and [excellent result] comes down to [key factor].

That's why we built [Product] - to help [audience] [achieve specific outcome].

[Proof point]

[CTA]
```

## Ad Copy Checklist

- [ ] Hook in first 3 seconds / first line
- [ ] Clear benefit (not just features)
- [ ] Single focused message
- [ ] Appropriate for platform
- [ ] CTA is clear and compelling
- [ ] Character limits respected
- [ ] Urgency/scarcity (if real)
- [ ] Social proof included
- [ ] Consistent with landing page
- [ ] Multiple variants for testing
